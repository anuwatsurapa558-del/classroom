ระบบห้องเรียน ฉบับแก้ไข v15.3

วิธีติดตั้ง
1. สำรองไฟล์เว็บเดิมไว้ก่อน
2. อัปโหลด classroom_app.html, apple-touch-icon.png และ favicon-32.png ไว้ในโฟลเดอร์เดียวกันบน GitHub Pages
3. หากหน้าเว็บเดิมมีชื่ออื่น ให้เปลี่ยนชื่อ classroom_app.html ให้ตรงชื่อเดิมก่อนอัปโหลด
4. เปิดเว็บใหม่แล้วทดสอบเพิ่มช่องคะแนน 1 ช่อง บันทึกคะแนน และรีเฟรชเพื่อตรวจว่าข้อมูลคงอยู่
5. บน iPhone/iPad เปิดเว็บด้วย Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม หากมีไอคอนเก่า ให้ลบทางลัดเก่าแล้วเพิ่มใหม่

สิ่งที่แก้
- เพิ่มฟังก์ชันที่ขาดสำหรับจัดการช่องคะแนน เพิ่ม/แก้ไข/ลบช่องคะแนน บันทึกคะแนน เกรด ร และหมายเหตุ
- ตรวจคะแนนเต็มไม่ให้เกินคะแนนเก็บที่เหลือ
- ปรับคะแนนเดิมตามสัดส่วนเมื่อแก้ไขคะแนนเต็ม โดยเก็บความละเอียดภายในและแสดงจำนวนเต็ม
- ยืนยันชื่อช่องก่อนลบ
- ใช้ไอคอนสมุดสีขาวและเครื่องหมายถูกสีมิ้นต์บนพื้นม่วงพาสเทล

การตรวจสอบ
ผ่านการตรวจไวยากรณ์ JavaScript และการทดสอบฟังก์ชันด้วยฐานข้อมูลจำลอง ยังไม่ได้ทดสอบการบันทึกบนฐานข้อมูลจริงหรือไอคอนบนอุปกรณ์ iOS จริง
ใช้ตาราง grade_components, grade_component_scores และ grade_overrides ที่ไฟล์เดิมโหลดอยู่แล้ว หากขึ้นข้อความว่าตารางไม่พบหรือไม่มีสิทธิ์บันทึก ให้ส่งข้อความผิดพลาดมาตรวจสอบ ไม่ควรเปิดสิทธิ์ฐานข้อมูลสาธารณะเพื่อแก้ปัญหา
การปรับคะแนนเต็มใช้หลายคำสั่งฐานข้อมูลพร้อมการคืนค่าเมื่อเกิดข้อผิดพลาด ควรหลีกเลี่ยงการแก้ช่องเดียวกันพร้อมกันหลายเครื่อง
