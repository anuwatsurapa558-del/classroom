Class Room v17.1 — Dashboard / Timetable / School name / Icons
============================================================

สรุปที่ปรับ
1. ชื่อโรงเรียนแสดงเต็มด้วยการขึ้นบรรทัดและปรับขนาดอักษรตามความยาว ทั้งการ์ดโรงเรียนและแถบเมนูซ้าย
2. โลโก้ด้านขวาบนขนาดกะทัดรัด (28px บนจอใหญ่ / 26px บนมือถือ)
3. Dashboard จัดสัดส่วนใหม่ เพิ่มเมนูลัด และย่อการ์ดให้เห็นภาพรวมง่ายขึ้น
4. แสดงรายวิชาที่ดูแลทุกวิชา ทุกห้องของภาคเรียนปัจจุบัน และคลิกเพื่อเปิดคะแนนของวิชานั้นโดยตรง
5. ตารางสอนมุมมองรวม: ปุ่ม แก้ไขภาพรวม + แก้ไข/ลบแต่ละคาบในตาราง และหน้ารายห้อง
   - แก้ไขคาบด้วย ID เดิม (ไม่สร้างใหม่): แก้ วัน เวลา วิชา/กิจกรรม หมายเหตุ
   - ลบคาบ: ยืนยันชื่อวิชา ห้อง วัน เวลา แล้วส่งลบไป Supabase
   - ไม่ลบข้อมูลวิชา คะแนน นักเรียน หรือผลสอบ
6. เพิ่มไอคอน SVG คุณภาพเวกเตอร์ที่ v17 เรียกใช้ แต่ขาดจาก ZIP เดิม และปรับขนาดไอคอน
7. ฝั่งนักเรียนคงโค้ดเดิมทุกฟังก์ชัน เพิ่ม CSS ปรับขนาดไอคอนและไฟล์ SVG ที่ครบชุด

วิธีติดตั้ง
- สำรองไฟล์เดิมใน GitHub ก่อน
- แตก ZIP แล้ว Upload files ทุกไฟล์ไปที่ root ของ repository classroom
  (ให้ classroom_app.html, student_app.html และ cr_*.svg อยู่ระดับเดียวกัน)
- Commit changes จากนั้นรีเฟรชบนมือถือ/คอมพิวเตอร์
- ไม่ต้องรัน SQL เพิ่ม (ใช้ schema เดิม)

คำแนะนำตรวจสอบ
- ตรวจว่าชื่อโรงเรียนยาวแสดงครบ
- ตรวจ Dashboard: มีรายวิชาทั้งหมด และคลิกตรงรายวิชาที่ต้องการได้
- ตารางสอน > ทุกห้องรวม > แก้ไขภาพรวม > ลองแก้คาบทดสอบ
- ลองลบเฉพาะคาบทดสอบ แล้วรีเฟรชเพื่อยืนยันว่าหายจาก Supabase
- ทดสอบบันทึกคะแนน, ช่องคะแนนเพิ่มเติม, เช็กชื่อ, แบบทดสอบ, ประกาศ และนักเรียนจากอุปกรณ์ที่ใช้งานจริง

การทดสอบ
- Node.js syntax check: ผ่าน HTML สองไฟล์
- Browser test ด้วยข้อมูลจำลองและ Supabase mock: ผ่านการเปิดภาพรวม, แสดงวิชาทั้งหมด,
  เปิด Modal แก้ไข, อัปเดตคาบเดิม และลบคาบเฉพาะแถว
- ไม่ได้เชื่อมต่อ Supabase จริงของโรงเรียน; หากพบ error ด้านสิทธิ์ RLS เมื่อแก้/ลบคาบ
  ต้องตรวจ policy ของตาราง timetable โดยไม่เปิดสิทธิ์สาธารณะเกินจำเป็น
