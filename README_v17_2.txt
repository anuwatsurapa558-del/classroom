1. ตัดเงาเบลอใน SVG และ CSS ให้ขอบไอคอนคมขึ้น (ครูและนักเรียน)
2. เพิ่มปุ่ม “แก้ไขชื่อ” บนแบนเนอร์ต้อนรับหน้าแดชบอร์ดครู

3. ชื่อโรงเรียนในข้อมูลพื้นฐานและ Sidebar ปรับขนาดตัวอักษรอัตโนมัติให้ลงบรรทัดเดียว

วิธีติดตั้ง: แตก ZIP อัปโหลดไฟล์ HTML, SVG, manifest และ PNG ทั้งหมดไปที่ GitHub repository classroom
