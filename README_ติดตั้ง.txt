Class Room v17 — Pastel 3D UI (เว็บครู + นักเรียน)

สร้างจากระบบครู v16.2 (รวมการแก้จัดการช่องคะแนนแล้ว) และเว็บนักเรียน v16.1 Responsive
ทำเฉพาะการจัดวางเมนู สไตล์ ไอคอน และกล่องแสดงข้อมูล โดยใช้ฟังก์ชันและ Supabase เดิม

ขั้นตอน
1) สำรอง classroom_app.html และ student_app.html ที่ใช้งานอยู่ก่อน
2) แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง root ของ repo classroom
   (ต้องเป็นระดับเดียวกับ classroom_app.html และ student_app.html)
3) Commit changes → รอ GitHub Pages อัปเดต → เปิดเว็บครู/นักเรียนในแท็บใหม่
4) ทดสอบเมนู เพิ่ม/จัดการช่องคะแนน เช็กชื่อ แบบทดสอบ ประกาศ และการเข้าสู่ระบบ
5) ไม่ต้องรัน SQL เพิ่ม

NOTE: ยังไม่ได้ทดสอบกับ Supabase ของคุณจริง; โปรดทดสอบกับข้อมูลจำลองก่อนใช้จริง
